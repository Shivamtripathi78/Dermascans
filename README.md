# 🔐 Python Password Strength Checker

A Python command-line application that evaluates password characteristics and provides suggestions for creating stronger passwords.

## ✨ Features

- Check password length
- Detect uppercase and lowercase letters
- Identify numbers and special characters
- Calculate a strength score
- Classify passwords by strength
- Provide improvement suggestions
- Hide password input in supported terminals
- No password storage or network transmission

## 🛠️ Technologies Used

- Python
- String manipulation
- Conditional statements
- Functions
- `getpass` and `string` modules

## 🚀 Getting Started

### Prerequisites

Python 3 must be installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/python-password-strength-checker.git
```

Navigate to the project folder:

```bash
cd python-password-strength-checker
```

Run the application:

```bash
python main.py
```

## 📊 Strength Evaluation

The checker evaluates:

- Password length
- Lowercase letters
- Uppercase letters
- Numeric characters
- Special characters

It calculates a score out of 6 and provides suggestions based on the checks that fail.

## 🔒 Privacy

The application checks passwords locally and does not intentionally save or transmit them.

Use fictional passwords for testing. This educational tool is not a substitute for a comprehensive password-security assessment.
